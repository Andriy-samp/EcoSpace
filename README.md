# 🌿 Студія EcoSpace — Лендінг вертикального озеленення

Сучасний, легкий та адаптивний односторінковий сайт (лендінг) для студії еко-дизайну **EcoSpace**. Сайт презентує послуги з професійного вертикального озеленення, встановлення автоматизованих фітостін та панелей зі стабілізованого моху для приватних осель і бізнесу.

## 🚀 Функціонал та особливості

* **Семантична розмітка:** Написано на чистому HTML5 з дотриманням стандартів доступності.
* **SEO & Open Graph Ready:** Налаштовані базові мета-теги та розмітка OG для коректного відображення посилань у соцмережах та месенджерах.
* **Аналітика:** Вбудовано підключення Google Tag Manager (Google Analytics).
* **Сучасний UX:** Реалізовано плавний скрол до розділів та ефект інтерактивного підсвічування за курсором (`.cursor-glow`).
* **Оптимізація:** Для зображень активовано ліниве завантаження (`loading="lazy"`).

## 🛠️ Використані технології

* HTML5 (Семантичний код)
* CSS3 (Flexbox/Grid, кастомні ефекти)
* Vanilla JavaScript (керування ефектом Glow)
